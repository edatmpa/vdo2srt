HOW TO RUN vdo2srt ON WINDOWS
==============================

0. First time on a PC (or if a launcher says the venv is missing/broken):
   double-click  setup.bat  once - it builds the Python environment for this PC
   (with the NVIDIA GPU libraries, since this PC has an RTX 3060 Ti).
1. Open File Explorer and navigate to E:\Plex Utility\vdo2srt
2. Double-click  vdo2srt.bat  - a menu appears:
     1) Convert video/audio to subtitles   2) Batch a list of folders
     3) Translate existing SRT only         4) Exit
3. Answer the prompts (Enter = default). For the file/folder prompt you can
   leave it blank to get a picker, or type/paste a path - with or without
   quotes, e.g. Explorer's "Copy as path" works as-is.
4. Engine: 1 = Local GPU, 2 = Local CPU, 3 = Google Cloud (blank = picker)
5. Source language (blank = auto-detect), translate Y/n, target language,
   and whether to redo existing output.
6. A terminal window opens and shows progress.
   When done, two files are saved beside each video:
     film.srt      — subtitles in the original language
     film.en.srt   — English translation (DeepL or free Google, see translate_routing.txt)

▎ Tip: If the terminal closes too fast to read an error, run it from a terminal instead (see below).

---
FROM A TERMINAL (Command Prompt or PowerShell)

1. Press Win + R, type cmd, press Enter
2. Run:
     "E:\Plex Utility\vdo2srt\vdo2srt.bat" "E:\path\to\your\movie.mkv" --engine local --language ru

ex:  "E:\Plex Utility\vdo2srt\venv\Scripts\python.exe" "E:\Plex Utility\vdo2srt\vdo2srt.py" "E:\Plex Utility\vdo2srt\video\Укрощение огня.  1 серия.mp4" --engine local --language ru 2>&1


The terminal stays open so you can read the output.

---
COMMON COMMAND-LINE EXAMPLES

:: GUI mode — dialogs for file/folder and method
"E:\Plex Utility\vdo2srt\vdo2srt.bat"

:: Single Russian film, GPU, with automatic English translation (default)
"E:\Plex Utility\vdo2srt\vdo2srt.bat" "E:\Movies\film.mkv" --engine local --language ru

:: Skip translation (original subtitles only)
"E:\Plex Utility\vdo2srt\vdo2srt.bat" "E:\Movies\film.mkv" --engine local --language ru --no-translate

:: Translate to a language other than English
"E:\Plex Utility\vdo2srt\vdo2srt.bat" "E:\Movies\film.mkv" --engine local --language ru --target-language fr

:: English film, GPU
"E:\Plex Utility\vdo2srt\vdo2srt.bat" "E:\Movies\film.mp4" --engine local --language en

:: Auto-detect language
"E:\Plex Utility\vdo2srt\vdo2srt.bat" "E:\Movies\film.mp4" --engine local

:: Tighter subtitle splitting (4 seconds instead of default 6)
"E:\Plex Utility\vdo2srt\vdo2srt.bat" "E:\Movies\film.mkv" --engine local --language ru --max-duration 4

:: Disable splitting entirely
"E:\Plex Utility\vdo2srt\vdo2srt.bat" "E:\Movies\film.mkv" --engine local --language ru --max-duration 0

:: Save SRT to a different location (single-file mode only)
"E:\Plex Utility\vdo2srt\vdo2srt.bat" "E:\Movies\film.mkv" --engine local -o "E:\Subtitles\film.srt"

:: Google Cloud engine
"E:\Plex Utility\vdo2srt\vdo2srt.bat" "E:\Movies\film.mkv" --engine cloud --language ru --credentials "E:\API Key\Google API Keys\speech2txt.json"

---
BATCH MODE — Process an entire folder at once

:: GUI mode — folder picker and method picker appear automatically
"E:\Plex Utility\vdo2srt\vdo2srt.bat"

:: Command-line batch (pass a folder path instead of a file path)
"E:\Plex Utility\vdo2srt\vdo2srt.bat" "E:\Movies"
"E:\Plex Utility\vdo2srt\vdo2srt.bat" "E:\Movies" --engine local --language ru
"E:\Plex Utility\vdo2srt\vdo2srt.bat" "E:\Movies" --engine local --language ru --no-translate
"E:\Plex Utility\vdo2srt\vdo2srt.bat" "E:\Movies" --engine local --language ru --target-language fr
"E:\Plex Utility\vdo2srt\vdo2srt.bat" "E:\Movies" --engine cloud --language ru --credentials "E:\API Key\Google API Keys\speech2txt.json"

:: Re-process files that already have a .srt file
"E:\Plex Utility\vdo2srt\vdo2srt.bat" "E:\Movies" --engine local --language ru --overwrite

Files that already have a matching .srt are skipped automatically (unless --overwrite is passed).
